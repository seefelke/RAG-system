Installation:
1. Clone repository
2. Install requirements.txt to your environment
3. Install Ollama
4. Install Mistral-Nemo in Ollama https://huggingface.co/mistralai/Mistral-Nemo-Instruct-2407
5. Add your OpenAI key to your environment as 'OPENAI_API_KEY'
6. Add your Pinecone key to your environment as 'PINECONE_API_KEY'

Usage:
1. Adjust config file to your liking
2. Start Frontend file to start the frontend
    OR
    Start Testing file to start RAG data collection
    OR
    Start main file (adjust folder path inside) to extract data from a dataset, enable generate_groundtruth line to generate ground truth data
